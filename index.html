二、Lam 面試 30 題

回答以「新人但有工程思維」為主，不要假裝自己已經有 Fab 設備經驗。

01你知道 Lam Research 是做什麼的嗎？
Lam Research 是半導體設備商，主要提供晶圓製造相關設備與服務，核心製程包含薄膜沉積、蝕刻、清洗，以及製程監控。我比較有興趣的是 Deposition 和 CVD，因為我的化工背景與 CVD 製程分析專案都跟製程參數及薄膜形成有關。
02為什麼想加入 Lam？
我希望自己的第一份工作可以真正接觸半導體設備，而不是只停留在理論。我本身是化工背景，也自己做過 CVD 製程良率分析，所以希望把製程知識進一步延伸到實際設備 troubleshooting。Lam 的工作很接近晶圓廠第一線設備，我認為這是累積半導體實務經驗很好的環境。
03為什麼不是直接去晶圓廠，而是設備商？
我希望先從設備端建立扎實的基礎。晶圓廠看到的是整個製程結果，而設備商的工程師需要更深入理解設備本身、異常原因以及如何恢復設備狀態。我覺得這跟我喜歡 troubleshooting、拆解問題的個性很接近。
04為什麼化工背景想做設備工程師？
我不認為化工和設備是完全不同的領域。化工訓練讓我熟悉製程、材料、傳質、反應和參數之間的關係，而半導體設備其實也是把這些製程條件穩定地控制在很小的範圍內。我希望把原本的製程基礎延伸到設備端。
05你對 Lam 哪個技術最有興趣？
CVD／Deposition。因為我本身就是化工背景，而且畢業後自己做過 CVD Yield Analysis。我對 Temperature、Pressure、Gas Flow、Film Thickness 和 Yield 之間的關係比較有興趣，也希望進一步了解這些製程結果背後實際是由哪些設備模組控制。
06你知道 Lam 的產品主要應用在哪裡嗎？
主要是晶圓製造中的關鍵製程，例如薄膜沉積、蝕刻、清洗，以及製程監控。Lam 的設備會直接進入客戶 Fab，協助客戶製造先進半導體。
07你知道 FSE 在做什麼嗎？
我理解 FSE 不只是修機器，而是站在客戶現場，負責設備安裝、維護、故障診斷和 troubleshooting，目標是盡快找到問題並降低 downtime，同時也要跟客戶保持良好溝通。
08你知道 FSE 最重要的能力是什麼？
我認為是 troubleshooting 和溝通。技術上要能把問題拆解、診斷、隔離；但在客戶現場，也必須讓客戶知道目前發生什麼、正在做什麼以及下一步是什麼。
09可以接受 Cleanroom 嗎？
可以。我知道半導體設備工程師很多時間是在 Cleanroom 工作，需要穿著完整防護裝備，而且可能長時間站立、走動或進行設備操作。我對這樣的工作型態有心理準備。
10可以接受輪班、On-call、出差嗎？
如果工作安排清楚，我可以配合輪班、on-call 及必要的出差。我知道設備工程不是固定朝九晚五，設備異常可能發生在任何時間。
11什麼是 CVD？
CVD 是 Chemical Vapor Deposition，利用氣相反應物在晶圓表面發生反應或分解，形成固態薄膜。
12CVD 有哪些重要參數？
Temperature、Pressure、Gas Flow、Process Time。不同製程還可能涉及 RF Power、Gas Ratio、Chamber Condition 等。
13Pressure 為什麼重要？
Pressure 會影響氣體分子碰撞、反應物傳輸以及 plasma 或 surface reaction 的狀態，因此可能影響沉積速率、膜厚、均勻性及製程穩定性。
14Gas Flow 為什麼重要？
Gas Flow 會影響反應物供應以及不同氣體之間的比例。如果流量不穩定或比例改變，可能造成 deposition rate、film properties 或 uniformity 的變化。
15Temperature 為什麼重要？
CVD 的化學反應通常對溫度非常敏感，Temperature 改變可能影響反應速率、沉積速率以及薄膜特性，所以設備的溫度控制穩定性很重要。
16Deposition 跟 Etch 有什麼差別？
Deposition 是把材料加上去；Etch 是把不需要的材料移除。Lam 兩個領域都有重要產品。
17RIE 是什麼？
Reactive Ion Etching，是利用電漿產生帶電粒子，透過化學反應與離子作用來移除材料的一種蝕刻技術。
18ALD 和 CVD 有什麼差別？
CVD 通常是連續的薄膜沉積反應，而 ALD 是透過循序的表面反應，一次控制非常薄的材料層，因此對超薄膜與高深寬比結構具有很好的厚度控制能力。
19什麼是 Yield？
Yield 可以理解成符合規格、沒有缺陷或成功完成要求的產品比例。對半導體製造來說，Yield 直接影響製造效率與成本。
20如果 Yield 突然下降，你會先看什麼？
我會先確認 Yield 下降的時間點，再比較正常與異常批次，接著看 Temperature、Pressure、Gas Flow 等製程參數是否有變化，再確認是哪一台 Tool、哪個 Recipe 或哪個時間區段集中發生。如果有設備異常，就進一步看 Alarm、Log、PM、Calibration 或維修紀錄。
21你為什麼做這個 CVD Project？
因為我的背景是化工，但希望進一步進入半導體，所以我想用一個實際專案把化工製程思維延伸到半導體。我選 CVD 是因為它跟化工的反應、傳質和製程控制很有關聯。
22你的 CVD Project 做了什麼？
我分析 500 筆模擬的半導體 CVD 製程資料，包含 Temperature、Pressure、Gas Flow、Film Thickness、Defect、Tool ID 和 Yield。從資料整理開始，做正常／異常批次比較、統計分析、設備差異及時間趨勢分析，最後把結果整理成技術報告和 GitHub Portfolio。
23你從這個 Project 發現什麼？
我發現異常批次和正常批次在幾個製程參數上有明顯差異，也看到不同 Tool 的異常率存在差異。因此我沒有直接把某個參數當成 root cause，而是把 Pressure、Temperature 和設備穩定性列為後續調查方向，再思考需要搭配設備 Log、Calibration、PM、CM 等資料驗證。
24你沒有真正半導體工作經驗，為什麼覺得自己可以？
我確實還沒有 Fab 現場工作經驗，所以我不會說自己已經具備實際設備 troubleshooting 能力。但我已經透過 CVD 專案開始建立製程分析與問題拆解能力。我希望進入 Lam 後接受完整訓練，把目前的理論與分析能力轉換成真正的設備實務能力。
25你的 Python 跟 FSE 有什麼關係？
我不認為 Python 本身就是 FSE 的核心技能，但它讓我習慣用數據看問題。例如設備發生異常時，我會想知道異常發生的時間、頻率、相關參數及前後變化。如果未來有設備 Log 或大量資料，我希望能利用 Python 協助分析，而不是只靠人工逐筆查看。
26如果設備突然 Alarm，你會怎麼做？
我會先確認 Alarm code、發生時間及設備目前狀態，了解問題是偶發還是持續發生。接著依照 SOP、manual 和 troubleshooting procedure，把問題範圍逐步縮小，例如確認 electrical、mechanical、vacuum、gas 或 sensor 等相關系統。找到可能原因後再進行 corrective action，最後確認設備恢復後重新驗證，並留下完整紀錄。如果超過自己的能力或權限，我會及時尋求資深工程師協助。
27如果你找不到問題怎麼辦？
我不會一直盲目嘗試。我會先確認目前已經排除了哪些可能性，再重新檢查問題定義與資料。如果仍無法判斷，我會整理目前的現象、Log、已做過的檢查和結果，帶著具體資訊向資深工程師請教。
28如果客戶一直催你，你怎麼辦？
我會先確認客戶最在意的是設備恢復時間、目前生產影響還是問題原因，然後把目前已確認的狀況、正在排查的項目和下一步清楚說明。即使問題還沒有解決，也會保持資訊透明，不會讓客戶完全不知道目前進度。
29如果資深工程師告訴你的方法跟你想的不一樣？
我會先理解他判斷的依據，而不是直接認為自己的方法比較好。因為我目前還是新人，現場經驗一定比不上資深工程師。我會把原因記錄下來，之後再思考這個判斷跟哪些設備現象或數據有關，讓下一次遇到類似問題時能自己處理。
30為什麼我們應該錄取你？
我沒有正式的半導體工作經驗，所以我不會把自己包裝成已經很懂設備的人。但我的優勢是學習速度和面對問題的方式。我是化工背景，做過製程研究，也自己完成過 CVD Yield Analysis，代表我是真的有花時間把自己往半導體方向準備，而不是只是因為產業熱門才想進來。如果有機會加入 Lam，我希望從最基本的設備和現場開始學，先把設備原理、troubleshooting 和客戶應對做好，再慢慢把自己的製程分析和數據能力帶進來。我比較期待的是，幾年後遇到設備問題時，我不只是知道怎麼修，而是能理解為什麼會發生、怎麼避免再次發生。

四、一分鐘自我介紹

您好，我是化學工程碩士畢業，研究期間主要接觸製程優化與實驗 troubleshooting。因為希望往半導體設備發展，畢業後我自己做了一個 CVD Yield Analysis 專案，分析 500 筆製程資料，使用 Python 和統計方法去看 Temperature、Pressure、Gas Flow、Tool variation 和 Yield 的關係。這個過程讓我發現自己很喜歡把一個看起來很模糊的問題拆開，再透過數據和驗證逐步找原因。雖然我目前還沒有實際 Fab 設備經驗，但我希望從 FSE 開始，把目前的製程分析能力轉成真正的設備 troubleshooting 能力。

五、你的 CVD 專案：面試時怎麼講

為什麼做？
化工背景，希望把製程思維延伸到半導體。

做了什麼？
分析 500 筆 CVD 製程資料，包含 Temperature、Pressure、Gas Flow、Film Thickness、Defect、Tool ID、Yield。

怎麼分析？
Normal / Abnormal 比較、統計分析、Tool 差異、時間趨勢、製程參數分析。

最重要的工程思維？
Correlation 不等於 Root Cause。 異常參數只能作為後續調查方向，還需要設備 Log、Calibration、PM、CM 等資料驗證。
